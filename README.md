# LastChance

Saving meals from waste — one rescue at a time.

This is a minimal starter for LastChance — a React + Vite + TypeScript app with Tailwind CSS. It includes stubbed auth and placeholder pages so you can run the UI locally.

Quick start:

1. Install dependencies:
   npm install

2. Run the dev server:
   npm run dev

3. Open http://localhost:5173

To publish:
- Create a public GitHub repo `tchuensi/LastChance` (or use your preferred owner/name).
- Commit and push these files, then enable GitHub Pages or connect CI/CD as needed.

If you want, I can produce a zip of this tree for you, or provide git commands to push it to your newly created repository.
